## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js v20.18.1 or higher (required)
- Git
- npm or yarn or pnpm

> **Important**: This template requires Node.js version 20.18.1 or higher. Using an older version will cause build failures and compatibility issues.

## Create project

1. Clone the repository:

<CodeBlock>
  git clone https://github.com/your-username/digital-marketing-template.git cd
  digital-marketing-template
</CodeBlock>

2. Install dependencies:

<CodeBlock>npm install --legacy-peer-deps</CodeBlock>

> **Note**: The `--legacy-peer-deps` flag is required due to some package dependencies. Without this flag, installation will fail.

3. Start the development server:

<CodeBlock>npm run dev</CodeBlock>

## Common Issues

1. **Node Version Error**:
   If you see dependency errors, ensure you're using Node.js v20.18.1 or higher:

   ```bash
   node --version
   ```

2. **Installation Failures**:
   Always use `--legacy-peer-deps` when installing:

   ```bash
   npm install --legacy-peer-deps
   ```

3. **Build Errors**:
   Make sure all dependencies are properly installed and you're using the correct Node version.
