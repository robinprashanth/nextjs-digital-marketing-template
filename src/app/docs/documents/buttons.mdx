## Usage

```tsx
import { Button } from "@/components/ui/button";
```

## Examples

### Default Button Variants

```tsx
<Button>Default Button</Button>
<Button variant="destructive">Destructive</Button>
<Button variant="outline">Outline</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="link">Link</Button>
```

### Custom Variants

#### Premium Button

A gradient button transitioning from green to tulip.

```tsx
<Button variant="premium">Premium Features</Button>
```

#### Glass Button

A translucent button with backdrop blur effect.

```tsx
<Button variant="glass">Glass Effect</Button>
```

#### Gradient Button

A gradient button transitioning between primary and indigo.

```tsx
<Button variant="gradient">Get Started</Button>
```

#### Submit Button

A rounded button with gradient and hover effects.

```tsx
<Button variant="submit">Submit Form</Button>
```

#### Action Button

A solid colored button with shadow and scale effects.

```tsx
<Button variant="action">Take Action</Button>
```

#### White Action Button

A white button with colored text and scale effect.

```tsx
<Button variant="white-action">Start Now</Button>
```

#### CTA Buttons

Two different call-to-action button styles.

```tsx
<Button variant="cta">
  Primary CTA
</Button>

<Button variant="cta2">
  Secondary CTA
</Button>
```

#### Text Link

A minimal text-style button with icon animation.

```tsx
<Button variant="text-link">
  Learn More <ArrowRight />
</Button>
```

#### Soft Button

A subtle button with background opacity.

```tsx
<Button variant="soft">Soft Action</Button>
```

#### Tag Button

A tag-style button for categorization.

```tsx
<Button variant="tag">Category</Button>
```

## Button Sizes

The button component supports various sizes:

```tsx
<Button size="default">Default Size</Button>
<Button size="sm">Small</Button>
<Button size="sm-rounded">Small Rounded</Button>
<Button size="lg">Large</Button>
<Button size="lg-rounded">Large Rounded</Button>
<Button size="xl">Extra Large</Button>
<Button size="icon">🔍</Button>
<Button size="fluid">Fluid Width</Button>
```

## Border Radius Options

```tsx
<Button rounded="default">Default Radius</Button>
<Button rounded="full">Full Radius</Button>
```

## Props

The Button component extends the standard HTML button attributes with these additional props:

```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?:
    | "default"
    | "destructive"
    | "outline"
    | "secondary"
    | "ghost"
    | "link"
    | "premium"
    | "glass"
    | "gradient"
    | "submit"
    | "action"
    | "white-action"
    | "cta"
    | "cta2"
    | "text-link"
    | "soft"
    | "tag";
  size?:
    | "default"
    | "sm"
    | "sm-rounded"
    | "lg"
    | "lg-rounded"
    | "xl"
    | "icon"
    | "fluid";
  rounded?: "default" | "full";
  asChild?: boolean;
}
```

## Accessibility

- All buttons are keyboard accessible
- Proper ARIA attributes are automatically applied
- Focus states are clearly visible
- Disabled states are properly handled

## Best Practices

1. Use appropriate variants for different contexts:

   - `cta` for primary actions
   - `soft` for secondary actions
   - `text-link` for navigation
   - `tag` for categorization

2. Maintain consistency:

   - Use similar button variants for similar actions
   - Keep size consistent within sections
   - Match button style to overall design theme

3. Consider accessibility:
   - Ensure sufficient color contrast
   - Provide hover and focus states
   - Include descriptive text for screen readers
