## NextJS MDX Configuration

This template uses [Next.js built-in MDX support](https://nextjs.org/docs/app/building-your-application/configuring/mdx). To configure MDX in your Next.js project:

1. Install required dependencies:

```bash
npm install @next/mdx @mdx-js/loader @mdx-js/react @types/mdx
```

2. Configure `next.config.ts`:

```javascript
const withMDX = require("@next/mdx")();

/** @type {import('next').NextConfig} */
const nextConfig = {
  pageExtensions: ["js", "jsx", "mdx", "ts", "tsx"],
};

module.exports = withMDX(nextConfig);
```

[View full MDX configuration in Next.js docs →](https://nextjs.org/docs/app/building-your-application/configuring/mdx)

## Creating a Blog Post

1. Create a new `.mdx` file in `src/app/(main)/blog/posts/`
2. Add the required frontmatter:

```mdx
---
title: "Your Blog Post Title"
excerpt: "A brief description of your post"
date: "2024-03-01"
author:
  name: "Author Name"
  avatar: "/images/team/author.jpg"
category: "Content Marketing"
tags: ["Marketing", "SEO", "Strategy"]
readTime: "8 min read"
coverImage: "/images/blog/your-post-cover.jpg"
featured: false
---

# Your Blog Post Title

Your content goes here...
```

## Frontmatter Fields

```typescript
interface BlogPostMetadata {
  title: string; // Post title
  excerpt: string; // Brief description
  date: string; // Publication date
  author: {
    name: string; // Author's name
    avatar: string; // Author's avatar path
  };
  category: string; // Post category
  tags: string[]; // Array of tags
  readTime: string; // Estimated read time
  coverImage: string; // Cover image path
  featured: boolean; // Featured post flag
}
```

## Writing Content

Blog posts support various MDX features:

### 1. Basic Markdown

```mdx
# Heading 1

## Heading 2

Regular paragraph with **bold** and _italic_ text.

- List item 1
- List item 2

1. Numbered item 1
2. Numbered item 2

> Blockquote example
```

### 2. Code Blocks

````mdx
```typescript
interface Example {
  name: string;
  count: number;
}
```
````

### 3. Tables

```mdx
| Header 1 | Header 2 |
| -------- | -------- |
| Cell 1   | Cell 2   |
```

### 4. Images

```mdx
![Alt text](/images/blog/example.jpg)
```

```typescript

```

Posts are automatically paginated based on this constant. Users can:

- Load more posts
- Filter by category

export async function getBlogPostBySlug(slug: string) {
  const fullPath = path.join(postsDirectory, `${slug}.mdx`);
  const fileContents = fs.readFileSync(fullPath, "utf8");

  return {
    frontMatter: data,
    content,
  };
