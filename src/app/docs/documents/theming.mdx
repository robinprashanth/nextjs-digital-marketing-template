## Usage

### Using Theme Colors in Tailwind

Colors are mapped in `tailwind.config.ts` and can be used with Tailwind classes:

```tsx
// Basic color usage
<div className="bg-theme-primary-500">Primary Background</div>
<div className="text-theme-secondary-400">Secondary Text</div>

// Gradient examples
<div className="bg-gradient-to-r from-theme-primary-400 to-theme-secondary-400">
  Gradient Background
</div>
```

### Utility Classes

The template includes several pre-built gradient utilities:

```css
/* Gradient Text */
.gradient-text {
  @apply bg-gradient-to-br from-theme-primary-500 via-theme-secondary-500 to-theme-primary-600 bg-clip-text text-transparent;
}

/* Gradient Background */
.bg-gradient-pop {
  background-image: linear-gradient(
    135deg,
    hsl(var(--theme-primary-400)) 0%,
    hsl(var(--theme-secondary-400)) 50%,
    hsl(var(--theme-primary-500)) 100%
  );
}
```

## Customization

### Changing Theme Colors

1. Update HSL values in `globals.css`:

```css
:root {
  /* Change primary purple to your brand color */
  --theme-primary-500: 260 90% 65%; /* New HSL values */

  /* Update secondary orange */
  --theme-secondary-500: 30 95% 53%; /* New HSL values */
}
```

2. Or use exact HEX colors in `tailwind.config.ts`:

```typescript
theme: {
  extend: {
    colors: {
      theme: {
        primary: {
          500: "#8A6FF9", // Your brand color
        },
        secondary: {
          500: "#FF8A65", // Your secondary color
        },
      },
    },
  },
}
```

### Dark Mode

Dark mode colors are defined in the `dark` class selector:

```css
.dark {
  --background: 0 0% 3.9%;
  --foreground: 0 0% 98%;
  /* ... other dark mode variables */
}
```

## Gradients

### Pre-defined Gradients

```css
/* Primary Gradient */
.bg-gradient-primary {
  background: var(--gradient-primary);
}

/* Dark Gradient */
.bg-gradient-dark {
  background: var(--gradient-dark);
}

/* Pop Gradient */
.bg-gradient-pop {
  background-image: linear-gradient(
    135deg,
    hsl(var(--theme-primary-400)) 0%,
    hsl(var(--theme-secondary-400)) 50%,
    hsl(var(--theme-primary-500)) 100%
  );
}
```

### Custom Gradients

```tsx
// Linear Gradient
<div className="bg-gradient-to-r from-theme-primary-400 via-theme-secondary-400 to-theme-ocean-400">
  Custom Gradient
</div>

// Radial Gradient
<div className="bg-[radial-gradient(ellipse_at_top,var(--theme-primary-400),var(--theme-secondary-600))]">
  Radial Gradient
</div>
```
